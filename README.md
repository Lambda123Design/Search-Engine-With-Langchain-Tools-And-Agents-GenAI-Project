# Search-Engine-With-Langchain-Tools-And-Agents-GenAI-Project
This Repository contains my working files of "Search Engine With Langchain Tools And Agents Project", an Gen AI Project

(i) Implemented an end-to-end AI search engine using LangChain, integrating open-source LLM models like Llama.

(ii) Developed a Streamlit web app where users can enter queries, provide API keys, and see real-time reasoning and execution of tools.

(iii) Created custom retrieval tools (RAG-based) alongside inbuilt tools like Wikipedia, Arxiv, and DuckDuckGo for accessing up-to-date information.

(iv) Used agents and AgentExecutors to intelligently orchestrate tools and LLMs, enabling the system to decide which tool to call based on the query.

(v) Maintained chat history and displayed agent thought processes using Streamlit callbacks to provide transparency in decision-making.

(vi) Demonstrated a fully functional generative AI search engine capable of answering complex queries using both LLM knowledge and external sources.
